# Configuration reference

This is the generated catalog of `config/shift-left.yaml` keys for operators who need types, defaults, restart behavior, and whether a path is repo-relative or container-absolute.

Generated from the Pydantic models in `services/orchestrator/shift_left/config.py` (schema_version **11**). Do not edit this file by hand.

Regenerate:

```bash
PYTHONPATH=services/orchestrator:services/shift-left-shared \
  .venv/bin/python scripts/generate_docs.py --config-ref
```

Copy `config/shift-left.example.yaml` or let `./shift-left up` write `config/shift-left.yaml`. A missing or mismatched `schema_version` refuses to start:

```
unsupported schema_version N (expected 11).
```

YAML `data/...` paths are repo-relative. Inside Compose, `SHIFT_LEFT_DATA_DIR=/data` maps them onto the writable volumes (`./data/findings:/data/findings`, `./data/repos:/data/repos`). Legacy container-absolute values such as `/shift-left/data/repos` are rewritten at load; the rewrite is visible on the system page. Do not point sqlite or checkouts at `/shift-left/data` — that bind-mount is read-only.

Operator-mutable model paths can also be changed from the system UI; quant and weight-path changes still require a model-server restart. Policy YAML is not hot-reloaded.
